## Rastreabilidade
A guia **Commits** no GitHub permite examinar cada alteração com data, mensagem e identificador. Para a evidência de clonagem local, consulte o guia de Git/GitHub.

## Observação
Os primeiros commits no GitHub foram registrados por integração de API autorizada, e não por um comando `git push` executado no computador do estudante.
