# Gerenciador de Ordens de Serviço — Gestão de Configuração

Projeto acadêmico de Python 3 para demonstrar gestão de configuração com Git e GitHub.

## Funcionalidades
- Cadastrar ordens de serviço;
- Listar ordens;
- Concluir uma ordem;
- Exibir resumo por status;
- Armazenar dados em JSON.

## Execução
```bash
python app.py listar
python app.py nova "Cliente Exemplo" "Notebook" "Não liga"
python app.py resumo
python -m unittest discover -s tests -v
```
